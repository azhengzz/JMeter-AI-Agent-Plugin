# Spec Delta

## MODIFIED Requirements

### Requirement: Markdown 渲染进样式化文档

助手回复与系统类消息中的 markdown SHALL 渲染为样式化文本：标题分级字号、粗体/斜体、行内代码（等宽 + 底色）、无序列表、围栏代码块、表格、分隔线。代码块 MUST 以带语言标签与复制按钮的独立代码组件呈现（内容等宽字体、复制反馈）；表格 MUST 以网格组件呈现且表头加粗区分。流式期间（流段未结束）的渲染与终态同路径：已闭合的围栏代码块与成形的表格（表头 + 分隔行 + 已到数据行）SHALL 即时渲染为内嵌组件（复制按钮/网格随流出现，流段结束无升级跳变）；尚未闭合的尾部围栏 SHALL 按等宽纯文本呈现，围栏闭合后即时升级为代码块组件。

#### Scenario: 代码块渲染与复制

- **WHEN** 助手回复包含围栏代码块（带语言标注）
- **THEN** 该块渲染为独立代码组件，头部显示语言标签与复制按钮；点击复制将代码原文写入剪贴板

#### Scenario: 表格渲染

- **WHEN** 助手回复包含 markdown 表格（含分隔行）
- **THEN** 表格渲染为网格组件，表头加粗可辨，单元格内竖线转义（`\|`）呈现为字面竖线

#### Scenario: 模型输出中的 HTML 不执行

- **WHEN** 助手回复或工具输出包含 HTML 标签文本（如 `<br>`、`<img ...>`）
- **THEN** 标签按字面文本呈现，不被解析为富文本；反引号代码 span 内的 `<br>` 变体同样保持字面

#### Scenario: 流式中的代码块与表格实时渲染

- **WHEN** 流式进行中累计正文包含已闭合的围栏代码块或表头 + 分隔行已成形的表格（流段尚未结束）
- **THEN** 该代码块/表格即时渲染为内嵌组件（复制按钮/网格）呈现于流式卡，数据行随流增长；尚未闭合的尾部围栏按等宽纯文本呈现，闭合后即时升级

### Requirement: 思考内容折叠卡

reasoning 思考内容 SHALL 呈现为可折叠卡且**正文默认收起**：流式思考期间正文闭合，运行态经头部动态指示（spinner + "Thinking…"）呈现，文本在闭合正文中持续累积；思考完毕头部切换为带单行预览的 "Thoughts" 总结行。用户可随时手动展开/收起（展开可实时观看流式思考）。整段替换（流式重试成功）SHALL 原地复用同一思考卡组件：替换/清空其内容后重渲，卡片位置与折叠态不变（默认收起口径下替换后保持闭合，不自动展开）。折叠态 SHALL 区分自动收起与用户手动折叠/展开：自动收起可被用户手势改变，此后 MUST NOT 强制改动用户的手动选择。

#### Scenario: 思考内容折叠展示

- **WHEN** 回合产生 reasoning 内容且随后回复正文开始渲染
- **THEN** 思考卡正文默认收起、头部为带预览的 "Thoughts" 单行；点击可展开完整内容

#### Scenario: 流式思考默认收起、运行态可见

- **WHEN** 回合产生流式 reasoning 内容
- **THEN** 思考卡正文闭合，头部显示 spinner + "Thinking…"；正文在闭合状态下持续累积（展开后内容完整）

#### Scenario: 思考完毕头部切换

- **WHEN** 思考流段结束（正文开始/回合终态/流段收尾）
- **THEN** 头部切换为带单行预览的 "Thoughts" 总结行；点击可展开/收起完整内容

#### Scenario: 整段替换原位复用且保持闭合

- **WHEN** 流式重试成功触发整段替换（思考与正文均更新）
- **THEN** 思考卡与正文卡为替换前的同一组件实例（位置不变），内容整体更新，不产生重复卡片；卡片保持折叠（不被自动展开）

#### Scenario: 用户手动展开/折叠不被打扰

- **WHEN** 用户已手动展开（或折叠）思考卡后整段替换或终态收尾发生
- **THEN** 卡片内容被更新，用户的手动折叠/展开选择保持不变
